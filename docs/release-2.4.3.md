# Lot client 2.4.3

Le lot `2.4.3` est une reconstruction propre du client validé : 2 723 fichiers sélectionnés, sans cache de shaders ni fichiers temporaires, avec les ressources personnalisées déjà intégrées.

Le correctif caméra est intégré directement dans l'archive principale (`bin32/version.dll` et `bin64/version.dll`). Le manifeste ne contient donc aucun chemin dupliqué et ne dépend pas d'une archive de surcharge.

La construction locale a été vérifiée sur les 14 archives ZIP et l'inventaire complet. Les fichiers sont publiés sur la release GitHub `v2.4.3`; les deux archives inchangées réutilisent leurs URL de la release `v2.4.0`.
